# 79 - 内部知识问答系统演示

> 对应文章：[内部知识问答：多源数据融合+权限过滤+引用溯源](../../../GenAI/10-实战项目篇/79-内部知识问答多源数据融合加权限过滤加引用溯源.md)

## 功能说明

演示企业内部知识问答系统的核心能力：
- 多源数据融合（Confluence/飞书/数据库模拟）
- 权限过滤（公开/部门/角色/个人四级）
- 引用溯源（精确到文档+段落）
- 端到端问答流水线

## 运行环境

- Python 3.10+
- 无额外依赖（纯标准库实现）

## 运行方式

```bash
python knowledge_qa_demo.py
```

## 预期输出

- 多源数据导入统计
- 不同用户的权限过滤结果对比
- 带引用溯源的问答结果
- 权限泄露防护演示
