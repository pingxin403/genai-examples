> 对应文章：[智能客服从0到1：RAG+工作流+人工兜底全实现](../../../GenAI/10-实战项目篇/77-智能客服从0到1-RAG加工作流加人工兜底全实现.md)

## 功能说明

演示生产级智能客服系统的核心能力：
- 意图识别（关键词+规则分类）
- RAG知识检索（简化版向量匹配）
- 回答生成与置信度检查
- 人工兜底（转人工触发条件）
- 多轮对话管理

## 运行环境

- Python 3.10+
- 无额外依赖（纯标准库实现）

## 运行方式

```bash
python smart_customer_service_demo.py
```

## 预期输出

- 知识库加载与意图识别结果
- RAG检索与回答生成
- 多轮对话模拟
- 人工兜底触发演示
