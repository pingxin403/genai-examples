# 78 - 代码生成助手演示

> 对应文章：[代码生成助手：上下文管理+代码安全审查](../../../GenAI/10-实战项目篇/78-代码生成助手上下文管理加代码安全审查.md)

## 功能说明

演示企业级代码生成助手的核心能力：
- 代码库索引（函数/导入提取）
- 上下文管理（相关代码检索）
- 安全审查引擎（SQL注入/硬编码密钥/eval检测）
- Prompt安全规范注入
- 代码生成与审查流水线

## 运行环境

- Python 3.10+
- 无额外依赖（纯标准库实现）

## 运行方式

```bash
python code_assistant_demo.py
```

## 预期输出

- 代码库索引结果
- 上下文检索演示
- 安全扫描结果（高危/中危/低危）
- 代码生成+审查流水线
