# 80 - AI内容审核系统演示

> 对应文章：[AI内容审核：多模态+规则引擎+人工复审](../../../GenAI/10-实战项目篇/80-AI内容审核多模态加规则引擎加人工复审.md)

## 功能说明

演示多模态内容审核系统的核心能力：
- 文本审核（敏感词+PII检测）
- 图片审核模拟（OCR+分类）
- 规则引擎（多级决策）
- 人工复审队列管理

## 运行环境

- Python 3.10+
- 无额外依赖（纯标准库实现）

## 运行方式

```bash
python content_moderation_demo.py
```

## 预期输出

- 文本审核结果（通过/拦截/复审）
- 图片审核模拟结果
- 规则引擎决策
- 人工复审队列操作
