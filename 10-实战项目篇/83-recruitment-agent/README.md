# 83 - 招聘助手Agent演示

> 对应文章：[招聘助手Agent：简历解析+匹配+面试邀约](../../../GenAI/10-实战项目篇/83-招聘助手Agent简历解析加匹配加面试邀约.md)

## 功能说明

演示智能招聘助手Agent的核心能力：
- 简历解析（姓名/邮箱/技能/经验提取）
- 岗位匹配（技能/经验/学历多维度评分）
- 候选人排序推荐
- 面试邀约自动生成

## 运行环境

- Python 3.10+
- 无额外依赖（纯标准库实现）

## 运行方式

```bash
python recruitment_agent_demo.py
```

## 预期输出

- 简历解析结果
- 岗位匹配评分
- 候选人排序
- 面试邀约邮件生成
