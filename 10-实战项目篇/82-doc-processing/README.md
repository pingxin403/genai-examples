# 82 - 文档智能处理演示

> 对应文章：[文档智能处理：OCR+表格识别+RAG的流水线](../../../GenAI/10-实战项目篇/82-文档智能处理OCR加表格识别加RAG的流水线.md)

## 功能说明

演示文档智能处理Pipeline的核心能力：
- 文档分类（发票/合同/报表/手册）
- OCR文字提取（模拟）
- 表格识别与结构化提取
- 发票字段提取
- 文档分块与知识入库

## 运行环境

- Python 3.10+
- 无额外依赖（纯标准库实现）

## 运行方式

```bash
python doc_processing_demo.py
```

## 预期输出

- 文档分类结果
- 表格识别与提取
- 发票信息结构化
- 文档分块与入库统计
