# 85 - AI应用框架对比演示

> 对应文章：[AI应用框架三国杀：LangChain vs LlamaIndex vs Haystack](../../../GenAI/11-生态与工具篇/85-AI应用框架三国杀LangChain-vs-LlamaIndex-vs-Haystack.md)

## 功能说明

演示三大AI应用框架的核心设计模式：
- LangChain风格：Chain式编排RAG
- LlamaIndex风格：Index优先的检索
- Haystack风格：Pipeline模块化设计
- 同一任务三种实现的对比

## 运行环境

- Python 3.10+
- 无额外依赖（纯标准库实现）

## 运行方式

```bash
python framework_comparison_demo.py
```

## 预期输出

- 三种框架风格的RAG实现对比
- 检索结果和生成结果展示
- 性能和设计差异分析
