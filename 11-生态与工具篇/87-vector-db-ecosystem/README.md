## 功能说明

演示向量数据库的核心操作和选型对比：
- 统一向量存储接口抽象
- Chroma风格（轻量嵌入式）实现
- PGVector风格（SQL+向量）实现
- 插入、检索、删除操作对比

## 运行环境

- Python 3.10+
- 无额外依赖（纯标准库实现）

## 运行方式

```bash
python vector_db_ecosystem_demo.py
```

## 预期输出

- 两种向量存储风格的操作演示
- 检索结果和相似度分数
- 性能和适用场景对比
