# 86 - Agent框架对比演示

> 对应文章：[Agent框架擂台：LangGraph vs AutoGen vs CrewAI](../../../GenAI/11-生态与工具篇/86-Agent框架擂台LangGraph-vs-AutoGen-vs-CrewAI.md)

## 功能说明

演示三大Agent框架的核心设计模式：
- LangGraph风格：状态图驱动的Agent
- AutoGen风格：对话驱动的多Agent协作
- CrewAI风格：角色驱动的团队任务
- 同一任务三种实现的对比

## 运行环境

- Python 3.10+
- 无额外依赖（纯标准库实现）

## 运行方式

```bash
python agent_framework_demo.py
```

## 预期输出

- 三种Agent框架风格的实现对比
- 状态图、对话、角色三种编排模式演示
- 控制力和灵活性差异分析
