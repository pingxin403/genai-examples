# 65 - 多租户向量隔离演示

> 对应文章：[多租户隔离：不同客户的知识在向量库怎么隔离？](../../../GenAI/08-AI安全与合规篇/65-多租户隔离不同客户的知识在向量库怎么隔离.md)

## 功能说明

演示向量数据库的三种多租户隔离策略：
- 集合级隔离（物理隔离）
- 分区级隔离（逻辑隔离）
- 标签过滤隔离（行级隔离）
- 跨租户泄露检测

## 运行环境

- Python 3.10+
- 无额外依赖（纯标准库实现）

## 运行方式

```bash
python multi_tenancy_demo.py
```

## 预期输出

- 三种隔离策略的插入和检索演示
- 跨租户隔离验证
- 租户删除与清理
- 各策略的统计信息对比
