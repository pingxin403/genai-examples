# 61 - AI安全三道防线演示

> 对应文章：[AI安全三道防线：输入过滤+输出检测+敏感词库](../../../GenAI/08-AI安全与合规篇/61-AI安全三道防线输入过滤加输出检测加敏感词库.md)

## 功能说明

演示AI系统的三层安全防护体系：
- 输入过滤：注入检测、PII脱敏、长度限制
- 输出检测：信息泄露检测、合规审查
- 敏感词库：关键词匹配、正则规则、动态更新

## 运行环境

- Python 3.10+
- 无额外依赖（纯标准库实现）

## 运行方式

```bash
python ai_security_demo.py
```

## 预期输出

- 正常请求通过三道防线的完整流程
- 注入攻击被输入过滤拦截
- PII信息被自动脱敏
- 模型输出中的敏感信息被输出检测拦截
