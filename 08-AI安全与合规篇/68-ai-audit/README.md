# 68 - AI审计记录演示

> 对应文章：[AI审计：记录谁、在什么时候、问了AI什么](../../../GenAI/08-AI安全与合规篇/68-AI审计记录谁在什么时候问了AI什么.md)

## 功能说明

演示AI系统的审计日志体系：
- 审计事件记录（查询、响应、安全事件）
- 审计查询引擎（按用户/时间/类型检索）
- 合规报告生成
- 哈希链完整性验证

## 运行环境

- Python 3.10+
- 无额外依赖（纯标准库实现）

## 运行方式

```bash
python ai_audit_demo.py
```

## 预期输出

- 模拟AI交互的审计日志记录
- 按用户查询审计记录
- 安全事件统计
- 月度合规报告
- 日志链完整性验证
