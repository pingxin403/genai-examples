# 64 - 模型输出签名演示

> 对应文章：[模型输出签名：如何证明结果来自你的系统？](../../../GenAI/08-AI安全与合规篇/64-模型输出签名如何证明结果来自你的系统.md)

## 功能说明

演示AI输出的签名与验证机制：
- 数字签名（HMAC-SHA256）
- 文本水印（同义词替换）
- 不可变审计日志（哈希链）
- 签名验证与篡改检测

## 运行环境

- Python 3.10+
- 无额外依赖（纯标准库实现）

## 运行方式

```bash
python output_signing_demo.py
```

## 预期输出

- AI输出的签名生成过程
- 签名验证（正常 vs 篡改）
- 文本水印嵌入与检测
- 审计日志链完整性验证
