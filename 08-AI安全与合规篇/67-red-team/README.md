# 67 - 红蓝对抗演示

> 对应文章：[红蓝对抗：如何模拟提示词注入攻击？](../../../GenAI/08-AI安全与合规篇/67-红蓝对抗如何模拟提示词注入攻击.md)

## 功能说明

演示AI系统的红蓝对抗演练框架：
- 红队攻击库（直接注入、角色扮演、编码绕过等）
- 蓝队防御系统（模式匹配、长度限制、零宽字符清理）
- 自动化攻防演练
- 漏洞报告与防御率统计

## 运行环境

- Python 3.10+
- 无额外依赖（纯标准库实现）

## 运行方式

```bash
python red_team_demo.py
```

## 预期输出

- 各类攻击用例的执行结果
- 防御拦截/攻击成功的详细报告
- 整体防御率统计
- 发现的漏洞列表
