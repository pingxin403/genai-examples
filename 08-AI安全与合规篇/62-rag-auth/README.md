# 62 - RAG权限集成演示

> 对应文章：[私有知识安全：RAG系统的权限怎么和Auth集成？](../../../GenAI/08-AI安全与合规篇/62-私有知识安全RAG系统的权限怎么和Auth集成.md)

## 功能说明

演示RAG系统的权限控制集成：
- 文档级权限元数据管理
- 向量检索的pre-filter（元数据过滤）
- 应用层post-filter（细粒度ACL校验）
- 多租户隔离与审计日志

## 运行环境

- Python 3.10+
- 无额外依赖（纯标准库实现）

## 运行方式

```bash
python rag_auth_demo.py
```

## 预期输出

- 不同租户用户检索结果的隔离验证
- 不同安全等级用户的权限过滤效果
- 跨部门访问控制演示
- 审计日志输出
