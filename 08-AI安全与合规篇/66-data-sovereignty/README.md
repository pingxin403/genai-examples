# 66 - 数据主权合规演示

> 对应文章：[数据主权：跨境知识检索的合规方案](../../../GenAI/08-AI安全与合规篇/66-数据主权跨境知识检索的合规方案.md)

## 功能说明

演示跨境知识检索的数据主权合规方案：
- 多区域向量存储（EU/APAC/NA）
- 区域路由与数据传输策略
- 联邦检索（跨区域摘要传输）
- 数据匿名化处理

## 运行环境

- Python 3.10+
- 无额外依赖（纯标准库实现）

## 运行方式

```bash
python data_sovereignty_demo.py
```

## 预期输出

- 本地检索结果
- 跨区域检索（允许/拦截）
- 数据匿名化处理效果
- 合规审计日志
