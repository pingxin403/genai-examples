# 73 - LLM评测平台演示

> 对应文章：[LLM评测平台：离线评估+在线监控+回归测试](../../../GenAI/09-AI平台工程篇/73-LLM评测平台离线评估加在线监控加回归测试.md)

## 功能说明

演示LLM评测平台的核心能力：
- 测试集管理
- 自动评估引擎（关键词匹配+安全检查+Token效率）
- 发布门禁（通过率+回归率检查）
- 版本回归对比

## 运行环境

- Python 3.10+
- 无额外依赖（纯标准库实现）

## 运行方式

```bash
python llm_eval_demo.py
```

## 预期输出

- 测试集创建
- 模型评估报告（通过率、Token效率）
- 新旧版本回归对比
- 发布门禁判定
