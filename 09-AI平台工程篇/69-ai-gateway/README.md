# 69 - AI Gateway演示

> 对应文章：[AI Gateway：统一的模型接入、路由、降级层](../../../GenAI/09-AI平台工程篇/69-AI-Gateway统一的模型接入路由降级层.md)

## 功能说明

演示AI Gateway的核心能力：
- 多模型路由引擎（优先级/成本/延迟/权重策略）
- 熔断器降级控制
- 语义缓存层
- 团队配额管理
- 调用指标统计

## 运行环境

- Python 3.10+
- 无额外依赖（纯标准库实现）

## 运行方式

```bash
python ai_gateway_demo.py
```

## 预期输出

- 多策略路由演示（优先级、成本优化、延迟优化）
- 模型故障自动降级
- 缓存命中演示
- 配额超限拦截
- 调用指标汇总
