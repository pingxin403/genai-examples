# 75 - 模型路由策略演示

> 对应文章：[模型路由策略：按场景、按成本、按延迟自动调度](../../../GenAI/09-AI平台工程篇/75-模型路由策略按场景按成本按延迟自动调度.md)

## 功能说明

演示智能模型路由的核心能力：
- 场景分类器（规则匹配）
- 多因素评分路由（成本/延迟/质量权重）
- 路由规则引擎
- 故障降级与恢复
- 路由统计

## 运行环境

- Python 3.10+
- 无额外依赖（纯标准库实现）

## 运行方式

```bash
python model_routing_demo.py
```

## 预期输出

- 不同场景的路由决策
- 多因素权重调整效果
- 模型故障自动降级
- 路由统计报告
