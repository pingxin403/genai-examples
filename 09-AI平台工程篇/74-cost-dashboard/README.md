# 74 - AI成本控制面板演示

> 对应文章：[AI成本控制面板：实时看Token消耗、预算预警](../../../GenAI/09-AI平台工程篇/74-AI成本控制面板实时看Token消耗预算预警.md)

## 功能说明

演示AI成本控制面板的核心能力：
- 多维度成本采集（团队/场景/模型/用户）
- 实时聚合引擎
- 预算预警（分级告警）
- 优化建议生成

## 运行环境

- Python 3.10+
- 无额外依赖（纯标准库实现）

## 运行方式

```bash
python cost_dashboard_demo.py
```

## 预期输出

- 模拟AI调用的成本记录
- 按团队/场景/模型/用户的成本拆分
- 预算预警检查
- 成本优化建议
