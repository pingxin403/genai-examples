# 🎭 系统提示词的企业级管理：版本化、A/B测试、灰度

> 配套文章：[《系统提示词的企业级管理：版本化、A/B测试、灰度》](../../../GenAI/02-Prompt工程篇/13-系统提示词的企业级管理版本化AB测试灰度.md)

## 功能简述

本示例演示企业级Prompt管理的核心能力：

1. **版本管理** — Prompt的注册、激活、回滚、历史查询
2. **A/B测试** — 基于用户ID哈希的流量分流，指标采集与对比
3. **灰度发布** — 金丝雀发布，逐步扩量，异常自动回滚

## 运行环境

- Python 3.10+
- 无外部依赖（纯标准库实现）

## 运行命令

```bash
python prompt_management_demo.py
```

## 输出示例

```
=== Prompt版本管理演示 ===
注册版本 v1.0.0 和 v1.1.0
激活 v1.0.0: customer_service / v1.0.0 [active]
回滚后: customer_service / v1.0.0 [active]

=== A/B测试演示 ===
用户 user_001 → v1.0.0
用户 user_002 → v1.1.0
实验结果: control=0.72, treatment=0.81

=== 灰度发布演示 ===
灰度5%: user_010 → v1.0.0
扩量到30%: user_010 → v1.1.0
全量发布完成: v1.1.0 [active]
```

## 核心设计

```
Prompt变更 → Git提交 → CI测试 → 灰度5% → 监控指标 → 逐步扩量 → 全量/回滚
```
