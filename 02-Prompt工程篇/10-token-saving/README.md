# 📦 5种省Token的实战技巧 — 代码示例

> 配套文章：《上下文窗口爆了？这是5种省Token的实战技巧》

## 功能简述

演示5种生产级省Token技巧：
1. **摘要压缩**：将长文本压缩为摘要，减少上下文占用
2. **滑动窗口**：只保留最近N轮对话，丢弃早期历史
3. **关键帧提取**：从长文本中提取结构化关键信息点
4. **检索增强（RAG）**：按需检索相关片段，而非全量塞入
5. **记忆裁剪**：按重要度评分，优先保留关键记忆

## 运行环境
