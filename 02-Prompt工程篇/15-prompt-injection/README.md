# 🔒 提示词注入攻击防护演示

对应文章：《提示词注入攻击：你的AI系统可能正在裸奔》

## 功能说明

演示提示词注入攻击的三层防护体系：

1. **输入过滤** - 正则模式匹配 + 敏感词检测 + 编码内容检测
2. **边界隔离** - 系统指令与用户输入的标记分离 + 转义处理
3. **输出检测** - 敏感信息泄露检测 + 业务规则校验 + 内容脱敏

## 运行环境

- Python 3.9+
- 无需额外依赖（纯标准库实现）
- 如需真实LLM调用，安装 `openai` 库

## 安装依赖

```bash
# 基础演示无需安装依赖
python prompt_injection_demo.py

# 如需真实LLM调用
pip install openai
```

## 运行命令

```bash
python prompt_injection_demo.py
```
