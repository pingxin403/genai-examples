# 🧩 分块（Chunking）策略实战示例

> 配套文章：《分块（Chunking）的艺术：语义边界vs固定大小》

## 功能简述

演示四种主流文档分块策略的实现与效果对比：

1. **固定大小分块** - 按字符数等间隔切割，支持重叠窗口
2. **递归字符分块** - 按分隔符优先级递归切割，保留段落完整性
3. **语义分块** - 基于embedding相似度检测语义边界
4. **文档结构分块** - 按Markdown标题层级切割

## 运行环境

- Python 3.10+
- numpy

## 依赖安装

```bash
pip install numpy
```

## 运行命令

```bash
python chunking_demo.py
```

## 输出说明

程序会对同一段示例文本分别使用四种分块策略，输出每种策略的分块结果、chunk数量、平均大小等统计信息，方便直观对比不同策略的效果差异。
