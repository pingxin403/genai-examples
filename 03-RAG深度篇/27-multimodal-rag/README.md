# 🧩 多模态RAG演示

> 配套文章：[多模态RAG：当图片、表格也成为检索对象](../../../GenAI/03-RAG深度篇/27-多模态RAG当图片表格也成为检索对象.md)

## 功能简述

演示多模态RAG的核心工程实现：

1. **图片描述生成**：按图片类型定制Prompt，生成检索友好的文本描述
2. **表格理解与结构化**：将表格解析为Markdown格式 + 自然语言摘要
3. **跨模态统一索引**：文本、图片描述、表格摘要统一Embedding和检索
4. **多模态检索与排序**：跨模态相似度计算 + 类型加权Rerank

## 运行环境

- Python 3.10+
- 无外部依赖（纯标准库实现）

## 运行命令

```bash
python multimodal_rag_demo.py
```

```

--- 2. 表格理解与结构化 ---
--- 3. 跨模态统一索引与检索 ---
--- 4. 完整多模态RAG Pipeline ---
```
