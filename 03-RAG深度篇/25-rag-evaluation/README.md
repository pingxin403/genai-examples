# 🧪 RAG效果评估框架

> 配套文章：[RAG效果怎么评估？召回率、忠实度、有用性全量化](../../../GenAI/03-RAG深度篇/25-RAG效果怎么评估召回率忠实度有用性全量化.md)

## 功能简述

演示RAG系统的完整评估框架，包括：
- **检索质量评估**：Hit Rate@K、MRR、NDCG@K
- **生成质量评估**：忠实度（Faithfulness）、相关性（Relevancy）、有用性（Usefulness）
- **在线指标采集**：用户采纳率、转人工率、满意度汇总
- **离线-在线映射**：评估集盲区发现、阈值门禁检查

## 运行环境

- Python 3.10+
- 无外部依赖（纯标准库实现）

## 运行命令

```bash
python rag_evaluation_demo.py
```
