# 🔍 混合搜索实战示例

> 配套文章：《混合搜索：向量+关键词，1+1>2的融合之道》

## 功能简述

演示混合搜索（Hybrid Search）的核心实现：

1. **BM25关键词搜索** - 基于词频和逆文档频率的经典检索算法
2. **向量语义搜索** - 基于Embedding余弦相似度的语义检索
3. **分数归一化** - Min-Max归一化和RRF倒数排名融合两种方法
4. **加权融合** - 可配置alpha权重的双路分数融合
5. **自适应alpha** - 根据query特征动态调整向量/关键词权重
6. **Rerank触发策略** - 基于分数差距的条件性精排触发

## 运行环境

- Python 3.10+
- numpy

## 依赖安装

```bash
pip install numpy
```

## 运行命令

```bash
python hybrid_search_demo.py
```

## 输出说明

程序会演示以下流程：
1. 构建BM25倒排索引和向量索引
2. 对多种类型的query分别执行纯向量搜索、纯BM25搜索、混合搜索
3. 对比三种搜索方式的Hit Rate和MRR指标
4. 展示自适应alpha和rerank触发策略的效果
