# 24-知识同步示例

> 配套文章：《知识更新了，向量库咋同步？CDC+版本控制方案》

## 功能说明

本示例演示CDC（Change Data Capture）驱动的知识同步管道：

1. **文件哈希CDC检测**：基于SHA256哈希检测文档新增/修改/删除
2. **带版本控制的向量同步**：旧版本软删除 + 新版本写入 + 版本号管理
3. **过期向量清理**：定时清理不活跃的旧版本chunk
4. **完整管道编排**：变更检测 → 增量同步 → 过期清理的端到端流程

## 运行环境

- Python 3.9+
- 无需额外依赖（纯标准库实现）

## 运行命令

```bash
python knowledge_sync_demo.py
```

```
============================================================

  第2轮同步: 检测到1个变更，同步完成
  清理过期向量: 清理6条
```
