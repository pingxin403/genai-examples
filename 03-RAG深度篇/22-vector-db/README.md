# 📈 向量数据库选型对比 Demo

> 配套文章：《向量数据库选型：Chroma/PGVector/Milvus/Qdrant对比》

## 功能说明

本Demo通过模拟基准测试，对比四款主流向量数据库在以下维度的表现：

1. **插入性能**：批量写入速度对比
2. **检索性能**：延迟(P50/P99)和召回率
3. **多租户过滤**：带租户条件的检索开销
4. **内存占用**：不同数据量下的资源消耗
5. **五维评分雷达图**：综合评分可视化

## 运行环境

- Python 3.9+
- 无需安装向量数据库（使用模拟基准测试）

## 依赖安装

```bash
pip install numpy
```

## 运行命令

```bash
python vector_db_benchmark.py
```

## 输出内容

- 四款数据库的模拟基准测试结果
- 五维评分对比表
- 不同数据量级下的选型建议
- 多租户场景性能对比
