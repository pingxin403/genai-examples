# 23-Rerank精排示例

> 配套文章：《Rerank精排：如何把Top 100变Top 10还不掉精度？》

## 功能说明

本示例演示三种Rerank精排策略：

1. **Cross-Encoder精排**：使用交叉编码器对候选文档重新排序
2. **业务规则融合**：将语义分数与部门匹配、时效性、文档类型等业务规则结合
3. **分级Rerank**：根据延迟预算动态选择快速/标准/精确模式

## 运行环境

- Python 3.9+
- 依赖库见下方安装命令

## 安装依赖

```bash
pip install sentence-transformers numpy
```

> 注意：首次运行会自动下载 `BAAI/bge-reranker-v2-m3` 模型（约1.1GB），需要网络连接。
> 如果没有GPU，模型会使用CPU推理，速度会慢一些但功能完全正常。

## 运行命令

```bash
python rerank_demo.py
```
