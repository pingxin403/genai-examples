# 🏗️ 生产级RAG Pipeline演示

> 配套文章：[生产级RAG Pipeline：从知识摄入到推理的全链路](../../../GenAI/03-RAG深度篇/26-生产级RAG-Pipeline从知识摄入到推理的全链路.md)

## 功能简述

演示生产级RAG Pipeline的核心组件，包括：
- **异步索引管道**：基于队列的文档处理，支持批量处理、自动重试、死信队列
- **数据版本管理**：快照创建、版本回滚、版本差异对比
- **监控告警**：延迟监控、命中率统计、告警规则检查
- **成本分析**：按租户拆分Token消耗，成本估算与预算预警

## 运行环境

- Python 3.10+
- 无外部依赖（纯标准库实现）

## 运行命令

```bash
python rag_pipeline_demo.py
```
