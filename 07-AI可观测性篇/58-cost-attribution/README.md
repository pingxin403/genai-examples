# 58 - 成本拆分演示

> 对应文章：[成本拆分：每个用户的每次对话花了多少钱？](../../../GenAI/07-AI可观测性篇/58-成本拆分每个用户的每次对话花了多少钱.md)

## 功能说明

演示AI成本的多维度拆分与分析：
- 按用户/场景/模型维度的成本聚合
- 实时成本计算（多模型定价）
- 异常高成本请求检测
- 成本优化建议生成

## 运行环境

- Python 3.10+
- 无额外依赖（纯标准库实现）

## 运行方式

```bash
python cost_attribution_demo.py
```

## 预期输出

- 模拟多用户多场景的Token消耗
- 多维度成本分析报表
- 异常检测与优化建议
