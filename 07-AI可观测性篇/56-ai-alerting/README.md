# 56 - AI告警设计演示

## 功能说明

演示AI系统专属的告警规则引擎：
- 多级告警规则（P0/P1/P2）
- 阈值告警、燃烧率告警、预算告警
- 成本燃烧率计算与预测
- 告警评估与触发

## 运行环境

- Python 3.10+
- 无额外依赖（纯标准库实现）

## 运行方式

```bash
python ai_alerting_demo.py
```

## 预期输出

- 模拟AI指标数据输入
- 告警规则评估与触发
- 成本燃烧率分析与预算预测
