# 60 - 模型退化检测演示

> 对应文章：[模型退化检测：线上效果突然变差，怎么发现？](../../../GenAI/07-AI可观测性篇/60-模型退化检测线上效果突然变差怎么发现.md)

## 功能说明

演示模型退化的自动检测与根因分析：
- 滑动窗口基线追踪
- Z检验漂移检测
- 多维度根因推断
- 回归测试框架

## 运行环境

- Python 3.10+
- 无额外依赖（纯标准库实现）

## 运行方式

```bash
python model_degradation_demo.py
```

## 预期输出

- 模拟正常期和退化期的指标数据
- 漂移检测告警与根因分析
- 回归测试结果
