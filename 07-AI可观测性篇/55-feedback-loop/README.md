# 55 - 用户反馈闭环演示

> 对应文章：[用户反馈闭环：点赞/点踩数据如何变成评估集？](../../../GenAI/07-AI可观测性篇/55-用户反馈闭环点赞点踩数据如何变成评估集.md)

## 功能说明

演示用户反馈的采集、关联和评估集构建：
- 显式反馈采集（点赞/点踩 + 上下文关联）
- 隐式反馈检测（重新提问、编辑行为）
- 反馈分类与统计
- 自动构建评估集

## 运行环境

- Python 3.10+
- 无额外依赖（纯标准库实现）

## 运行方式

```bash
python feedback_loop_demo.py
```

## 预期输出

- 模拟用户反馈采集过程
- 隐式反馈检测结果
- 评估集构建与统计信息
