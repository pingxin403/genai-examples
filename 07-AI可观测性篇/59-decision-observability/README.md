# 59 - 决策可观测性演示

> 对应文章：[决策可观测性：Agent的思考过程也能追踪](../../../GenAI/07-AI可观测性篇/59-决策可观测性Agent的思考过程也能追踪.md)

## 功能说明

演示Agent决策过程的追踪与回放：
- 决策节点记录（选择、备选项、推理、置信度）
- 工具调用追踪
- 思考链日志
- 决策过程回放

## 运行环境

- Python 3.10+
- 无额外依赖（纯标准库实现）

## 运行方式

```bash
python decision_observability_demo.py
```

## 预期输出

- 模拟Agent处理用户请求的完整决策过程
- 决策节点详情与工具调用记录
- 决策过程回放输出
