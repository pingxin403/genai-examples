# 53 - AI黄金信号采集演示

> 对应文章：[AI黄金信号：除了延迟/错误，还要看什么？](../../../GenAI/07-AI可观测性篇/53-AI黄金信号除了延迟错误还要看什么.md)

## 功能说明

演示AI系统专属的黄金信号采集与告警：
- 延迟指标：TTFT、TPOT、端到端延迟
- 质量指标：幻觉率、上下文召回率、格式合规率
- 成本指标：Token消耗、缓存命中率
- 采纳指标：用户采纳率、点赞率

## 运行环境

- Python 3.10+
- 无额外依赖（纯标准库实现）

## 运行方式

```bash
python ai_golden_signals_demo.py
```

## 预期输出

- 模拟多次AI请求的指标采集
- 输出聚合后的黄金信号摘要
- 基于阈值触发告警示例
