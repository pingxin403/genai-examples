# 57 - AI A/B测试框架演示

> 对应文章：[A/B测试：Prompt版本、RAG策略如何科学对比？](../../../GenAI/07-AI可观测性篇/57-AB测试Prompt版本RAG策略如何科学对比.md)

## 功能说明

演示AI系统的A/B测试框架：
- 基于用户ID的确定性分流
- 多指标采集与聚合
- 简化Z检验统计显著性分析
- 样本量计算

## 运行环境

- Python 3.10+
- 无额外依赖（纯标准库实现）

## 运行方式

```bash
python ab_testing_demo.py
```

## 预期输出

- 模拟Prompt A/B测试的分流与指标采集
- 统计分析结果（均值、Z分数、显著性）
- 样本量计算建议
