# 93 - RAG落地十大坑演示

> 对应文章：[RAG落地十大坑：分块不当、检索失败、上下文污染](../../../GenAI/12-避坑指南篇/93-RAG落地十大坑分块不当检索失败上下文污染.md)

## 功能说明

演示RAG落地中常见的十大坑及解决方案：
- 分块粒度分析器：对比不同分块大小的效果
- 上下文污染检测器：识别不相关的检索结果
- MMR多样性检索：避免重复结果
- RAG全链路诊断工具

## 运行环境

- Python 3.10+
- 无额外依赖（纯标准库实现）

## 运行方式

```bash
python rag_pitfalls_demo.py
```

## 预期输出

- 不同分块大小的效果对比
- 上下文污染检测结果
- MMR检索 vs 普通检索对比
- RAG诊断报告
