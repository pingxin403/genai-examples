# 05 - AI应用四层架构演示

> 对应文章：🧭《一张图看懂AI应用架构：从用户请求到大模型》

## 功能简述

演示AI应用的四层架构（应用层/编排层/模型层/基础设施层）如何组织代码，展示一次用户请求从入口到返回的完整链路。

## 运行环境

- Python 3.9+
- 无需额外依赖（使用模拟数据，不调用真实API）

## 运行方式

```bash
python ai_architecture_demo.py
```

## 代码结构

```
05-ai-architecture/
├── README.md                  # 本文件
└── ai_architecture_demo.py    # 四层架构完整演示
```

## 预期输出

程序会模拟一次完整的AI问答请求，展示：
1. 应用层：认证和会话管理
2. 编排层：RAG检索 + Prompt组装 + 输出校验
3. 模型层：LLM推理（模拟）+ 降级策略
4. 基础设施层：向量检索 + 指标记录

最终输出请求结果和系统指标汇总。
