# 📊 AI项目ROI计算器

> 配套文章：《老板问"AI值不值"？这是我算ROI的Excel模板》

## 功能简述

本示例提供一个完整的AI项目ROI计算工具，包含：

- **成本计算**：推理成本（Token消耗）+ 运营成本（工程维护、人审评测、基础设施）
- **收益计算**：成本节约 + 收入提升 + 风险降低 三条价值线
- **情景分析**：乐观/基准/悲观 三档情景建模
- **决策引擎**：基于ROI结果自动给出投资建议

## 运行环境

- Python 3.8+
- 无需额外依赖（纯标准库实现）

## 运行命令

```bash
python ai_roi_calculator.py
```
