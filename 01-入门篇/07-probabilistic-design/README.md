# 07 - 概率性系统的三层防御演示

> 对应文章：⚖️《概率性系统的设计哲学：接受不完美，但可控》

## 功能简述

演示概率性AI系统的三层防御设计模式：置信度评估、多级回退策略、人工兜底调度，展示如何让AI系统在"不完美"中保持可控。

## 运行环境

- Python 3.9+
- 无需额外依赖（使用模拟数据，不调用真实API）

## 运行方式

```bash
python probabilistic_design_demo.py
```

## 代码结构

```
07-probabilistic-design/
├── README.md                          # 本文件
└── probabilistic_design_demo.py       # 概率性系统三层防御完整演示
```

## 预期输出

程序会模拟三种不同置信度的用户请求，展示：
1. 高置信度请求 → AI直接回答
2. 中置信度请求 → 触发回退策略（缓存/规则引擎/安全话术）
3. 低置信度请求 → 触发人工兜底（转人工/创建工单）

最终输出各请求的处理路径和防御层级统计。
