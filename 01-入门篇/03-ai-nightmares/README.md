# 🧠 AI工程师的四大噩梦：幻觉、延迟、成本、评估

本目录包含AI应用四大核心挑战的监控与治理示例代码。

## 代码说明

| 文件 | 功能 |
|------|------|
| `ai_nightmares.py` | 四大噩梦的监控、检测与治理工具集 |

## 功能概览

- **幻觉检测**：基于引用-答案一致性的幻觉防线
- **延迟追踪**：P50/P95/P99分位数延迟监控
- **成本控制**：请求级+用户级双重Token预算闸门
- **评估门禁**：发布前自动化评估与回归检测

## 运行环境

- Python 3.9+
- 无额外依赖（纯标准库实现）

## 运行方式

```bash
python ai_nightmares.py
```
